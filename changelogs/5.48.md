# 5.48.0
Released 31st August 2026.

This is a minor feature release, including new blocks, a new world generator and various API additions.

**Plugin compatibility:** Plugins for previous 5.x versions will run unchanged on this release, unless they use internal APIs, reflection, or packages like the `pocketmine\network\mcpe` or `pocketmine\data` namespace.
Do not update plugin minimum API versions unless you need new features added in this release.

**WARNING: If your plugin uses the `pocketmine\network\mcpe` namespace, you're not shielded by API change constraints.**
Consider using the `mcpe-protocol` directive in `plugin.yml` as a constraint if you're using packets directly.

## General
- Added a `void` world generator. (@remminiscent)
  - Select it with `level-type=void` in `server.properties`, or `generator: void` in a `pocketmine.yml` worlds entry.
  - The world is empty apart from a 33x33 stone platform at y=-64, marked at its centre by a single cobblestone block at (0, -64, 0).
- Generators can now provide a spawn position derived from the world seed. Void worlds use this to place the spawn on the platform. (@remminiscent)
- Added the Party Blue text format code (`§w`). (@remminiscent)
- Updated Korean translations. (Crowdin contributors)

## Gameplay
- The following blocks have been added:
  - Heavy Core (@IvanCraft623)
  - Sulfur, Chiseled Sulfur, Polished Sulfur and Sulfur Bricks, each with slab, stairs and wall variants (@alvin0319)
  - Cinnabar, Chiseled Cinnabar, Polished Cinnabar and Cinnabar Bricks, each with slab, stairs and wall variants (@alvin0319)
  - Potent Sulfur (@alvin0319, @IvanCraft623)
- Chiseled bookshelves now play the insert and pickup sounds when a book is stored or taken. (@remminiscent)
- Fixed bamboo hitboxes not matching the random offset position drawn by the client. (@alvin0319)

## API
### `pocketmine\block`
- The following classes have been added:
  - `HeavyCore`
  - `PotentSulfur`
  - `WetPotentSulfur`
  - `EruptivePotentSulfur` (abstract)
  - `ContinuousPotentSulfur`
  - `CyclingPotentSulfur`
- Various `public static` generated methods added to `VanillaBlocks` for newly added blocks (see the Gameplay section)

### `pocketmine\block\tile`
- The following classes have been added:
  - `PotentSulfur` - tracks the remaining heartbeats until a cycling geyser changes phase

### `pocketmine\block\utils`
- The following classes have been added:
  - `RandomOffsetGenerator` - reproduces the client's `minecraft:random_offset` block component, used to align bamboo hitboxes with the rendered model

### `pocketmine\entity\object`
- The following methods have changed visibility:
  - `AreaEffectCloud->setRadius()` is now `public` (previously `protected`) (@IvanCraft623)

### `pocketmine\event\block`
- The following classes have been added:
  - `GeyserEruptionPulseEvent` - called for each upward pulse of an erupting Potent Sulfur geyser.

### `pocketmine\player`
- The following methods have been added:
  - `public Player->removeItemCooldown(Item $item) : void` - clears the player's cooldown for the given item. (@ItsMax123)

### `pocketmine\utils`
- The following constants have been added:
  - `TextFormat::PARTY_BLUE`
- The following properties have been added:
  - `public static Terminal::$COLOR_PARTY_BLUE`

### `pocketmine\world\generator`
- The following classes have been added:
  - `VoidGenerator`
- The following methods have signature changes:
  - `GeneratorManager::addGenerator()` now accepts an optional trailing `?\Closure $spawnPositionProvider` parameter, which receives the world seed and returns a `?Vector3`.
  - `GeneratorManagerEntry::__construct()` now accepts the same optional trailing parameter.
- The following methods have been added:
  - `public GeneratorManagerEntry->getSpawnPosition(int $seed) : ?Vector3`

### `pocketmine\world\sound`
- The following classes have been added:
  - `ChiseledBookshelfInsertSound`
  - `ChiseledBookshelfPickupSound`
  - `GeyserEruptionStartSound`
  - `GeyserEruptionBurstSound`
  - `GeyserContinuousEruptionStartSound`
  - `GeyserContinuousEruptionBurstSound`

## Internals
- Added a dependency on `axolotl-pm/xoroshiro128pp`, used by `RandomOffsetGenerator` to match the client's block offset hashing. (@alvin0319)
- `Server::startupPrepareWorlds()` now resolves a `GeneratorManagerEntry` instead of a generator class-string, so the generator's seed-derived spawn position can be applied when a world is created. (@remminiscent)
