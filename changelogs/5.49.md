# 5.49.0
Released 18th September 2026.

This is a minor feature and support release for Minecraft: Bedrock Edition 1.26.50 (display version 26.50).

**Plugin compatibility:** Plugins for previous 5.x versions will run unchanged on this release, unless they use internal APIs, reflection, or packages like the `pocketmine\network\mcpe` or `pocketmine\data` namespace.
Do not update plugin minimum API versions unless you need new features added in this release.

**WARNING: If your plugin uses the `pocketmine\network\mcpe` namespace, you're not shielded by API change constraints.**
Consider using the `mcpe-protocol` directive in `plugin.yml` as a constraint if you're using packets directly.

## General
- Added support for Minecraft: Bedrock Edition 1.26.50 (display version 26.50). (@alvin0319)
- Removed support for earlier versions.

## Gameplay
- Fences and thin blocks (such as glass panes, iron bars, and copper bars) now track and persist horizontal connection states as real block states rather than purely derived visuals. (@alvin0319)
- Stair corner shapes (`StairShape`) are now tracked and persisted as part of the block state and dynamically recalculated on neighbour block updates. (@alvin0319)
- Jukebox record playback now tracks server-side sound handle IDs to properly synchronize sound start and stop events with the client. (@alvin0319)

## API
### `pocketmine\block`
- `Fence` and `Thin` now implement `HorizontalConnectable`. (@alvin0319)
- `Stair` now serializes its `StairShape` as part of its block state. (@alvin0319)

### `pocketmine\block\utils`
- The following interfaces have been added:
  - `HorizontalConnectable` - implemented by blocks carrying horizontal connection states (north, east, south, west). (@alvin0319)
- The following traits have been added:
  - `HorizontalConnectableTrait` (@alvin0319)

### `pocketmine\world\sound`
- The following classes have signature changes:
  - `RecordSound::__construct()` now accepts an optional `int $serverSoundHandleId = 0` parameter. (@alvin0319)
  - `RecordStopSound::__construct()` now accepts an optional `int $serverSoundHandleId = 0` parameter. (@alvin0319)

## Internals
- Updated Bedrock data files and schemas for Bedrock 1.26.50 (`bedrock-protocol` ~62.0.0, `bedrock-data` ~6.9.0, `bedrock-block-upgrade-schema` ~5.4.0, `bedrock-item-upgrade-schema` ~1.19.0). (@alvin0319)
- `StaticPacketCache` now loads and caches jigsaw structures data, voxel shapes, and data-driven block palettes. (@alvin0319)
  - The following methods have been added to `StaticPacketCache`:
    - `public StaticPacketCache->getBlockPaletteEntries() : list<BlockPaletteEntry>`
    - `public StaticPacketCache->getJigsawStructureData() : JigsawStructureDataPacket`
    - `public StaticPacketCache->getVoxelShapes() : VoxelShapesPacket`
  - The following model classes have been added under `pocketmine\network\mcpe\cache\model`:
    - `VoxelShapeCellsData`
    - `VoxelShapeData`
    - `VoxelShapesData`
- `PreSpawnPacketHandler` now sends `JigsawStructureDataPacket` and `VoxelShapesPacket` before `StartGamePacket`. (@alvin0319)
- `PreSpawnPacketHandler` now populates data-driven block palette entries in `StartGamePacket`. (@alvin0319)
- `InGamePacketHandler` now silently discards `ServerboundDiagnosticsPacket`. (@alvin0319)
- `World` now tracks sound handle IDs for positional sounds with internal helper methods (`getNextSoundHandleId()`, `getSoundHandleId()`, and `removeSoundHandleId()`). (@alvin0319)
- `RecordSound` now encodes `PlaySoundPacket` and `RecordStartedPacket` instead of `LevelSoundEventPacket`. (@alvin0319)
- `RecordStopSound` now encodes `ClientboundUpdateSoundDataPacket` instead of `LevelSoundEventPacket`. (@alvin0319)

# 5.49.2
Released 14th October 2026.

This is a bugfix release.

**WARNING: If your plugin uses the `pocketmine\network\mcpe` namespace, you're not shielded by API change constraints.**
This release updates `bedrock-protocol` to a version that converts several protocol types from integer constants to enums, so plugins using packets directly may break.

## Fixes
- Fixed dragon egg teleporting outside the world (@kostamax27)
- Fixed several packet serializers and deserializers (@alvin0319)

## Internals
- `Compressor::getNetworkId()` has been renamed to `getNetworkType()` and now returns `CompressionAlgorithm` instead of `int`. (@IvanCraft623)
- `TypeConverter::coreGameModeToProtocol()` now returns the protocol `GameMode` enum, and `protocolGameModeToCore()` now accepts it. (@IvanCraft623)

## Miscellaneous
- Updated documentation and repository links to axolotl-pm's own. (@alvin0319, @Remminiscent)
- Updated translations from Weblate.
