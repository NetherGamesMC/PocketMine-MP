# 5.50.0
Released 17th October 2026.

This is a minor feature release introducing support for the NetherNet (WebRTC) network transport, a new transport registration API, and related networking improvements.

**Plugin compatibility:** Plugins for previous 5.x versions will run unchanged on this release, unless they use internal APIs, reflection, or packages like the `pocketmine\network\mcpe`, `pocketmine\nethernet`, or `pocketmine\data` namespace.
Do not update plugin minimum API versions unless you need new features added in this release.

**WARNING: If your plugin uses the `pocketmine\network\mcpe` or `pocketmine\nethernet` namespace, you're not shielded by API change constraints.**
Consider using the `mcpe-protocol` directive in `plugin.yml` as a constraint if you're using packets directly.

## General
- Added support for the NetherNet (WebRTC) network transport.
  - NetherNet is now the primary transport for Minecraft Bedrock. Clients will prefer NetherNet over RakNet when available and only fall back to RakNet if the server does not support NetherNet or if the client is unable to use it.
  - Requires the [`axolotl-pm/ext-webrtc`](https://github.com/axolotl-pm/ext-webrtc) PHP extension (`^0.3.1`). If `ext-webrtc` is not loaded or has an incompatible version, the `nethernet` transport is skipped with a warning (`pocketmine.server.transport.unavailable`) and other configured transports will still start.
  - If no configured transport can start any usable network interface (for example, if `transport.name` is set to `nethernet` only and `ext-webrtc` is not loaded), the server logs an emergency message (`pocketmine.server.transport.noneConfigured`) and aborts startup.
  - Added a new `transport` section in `pocketmine.yml`:
    - `transport.name`: comma-separated list of active transports (defaults to `nethernet,raknet`, up to 8 entries, case-insensitive). Unknown transport names are ignored with a warning (`pocketmine.server.transport.unknown`).
    - `transport.nethernet`: settings for the NetherNet transport:
      - `key-file` (default `nethernet.key`): path to the persistent server identity key relative to the data directory. If the file does not exist, a new key is generated automatically with `0600` permissions. Clients pin this public key on first join, so **server operators should back up `nethernet.key`**; losing or replacing it will prompt returning players to re-verify the server on their next connection.
      - `identity-domain`: operator domain or server name included in identity assertions (defaults to the server MOTD with formatting codes stripped, or the server name if the stripped MOTD is empty).
      - `ice-udp-mux`, `port-range`, `mtu` (620 to 4144, default 1200), `advertise-addresses`, and `ice-servers` (STUN/TURN servers for NAT traversal and relay).
      - `builtin-signaling`: controls the built-in HTTP signaling endpoint (`GET`/`POST /v1/join`) and LAN broadcast discovery:
        - **Firewall / port notice:** Because `transport.name` defaults to `nethernet,raknet` and `builtin-signaling.enabled` defaults to `true`, servers with `ext-webrtc` installed will automatically open a **TCP port** on the server's bind address (IPv4, and IPv6 when `enable-ipv6` is enabled) matching `server-port` from `server.properties` (unless overridden by `transport.nethernet.builtin-signaling.port`), and bind LAN discovery to **UDP `0.0.0.0:7551`** (`LanSignaling::DEFAULT_PORT`).
        - `tls`: optional PEM `certificate`, `key`, and `passphrase` (supports a `file:<path>` prefix to read the passphrase from a file relative to the data directory) for serving HTTP signaling over HTTPS.
        - `reverse-proxy`: allows resolving the client's real IP from a forwarded header (default `X-Forwarded-For`) when behind a reverse proxy. When `reverse-proxy.enabled` is `true`, `reverse-proxy.trusted-ips` must contain at least one IP address or CIDR block.
- RakNet (`raknet`) and related settings in `pocketmine.yml` (`network.upnp-forwarding`, `network.max-mtu-size`, and `network.enable-encryption`) have been deprecated in favour of NetherNet and will be removed in a future release.
  - A deprecation warning is now logged on server startup when the `raknet` transport is active (`pocketmine.server.raknet.deprecated`) or when `network.upnp-forwarding` is enabled (`pocketmine.server.upnp.deprecated`).
  - When `enable-query` is enabled without `raknet` active (e.g. NetherNet-only mode), `DedicatedQueryNetworkInterface` is automatically started on the server's UDP port(s) so GS4 Query continues to work.

## API
### `pocketmine\event\player`
- The following classes have been added:
  - `PlayerIdentityVerifyEvent` - called after the server has verified the player's login (JWT chain and transport identity key, if provided) and before the player is created, allowing plugins to perform custom identity checks.
    - Implements `Cancellable` and uses `PlayerDisconnectEventTrait` (`getDisconnectReason()`, `setDisconnectReason()`, `getDisconnectScreenMessage()`, `setDisconnectScreenMessage()`). Cancelling the event disconnects the player with the configured reason and screen message.
    - Provides `getSession() : NetworkSession`, `getPlayerInfo() : PlayerInfo`, `isAuthenticated() : bool`, `isAuthRequired() : bool`, `getClientPublicKey() : string`, and `getTransportIdentityKey() : ?TransportIdentityKey`.

### `pocketmine\network`
- The following interfaces have been added:
  - `Transport` - represents a network transport (e.g. RakNet, NetherNet) that creates network interfaces for player connections.
  - `TransportIdentityKey` - represents a client identity key established by the transport layer, used to bind a connection to the client's login public key.
- The following classes have been added:
  - `TransportIdentityException` - thrown by `TransportIdentityKey->verify()` when the client's login public key does not match the transport identity.
- The following methods have been added:
  - `public Network->registerTransport(string $name, Transport $transport) : void` - registers a transport under the given name (case-insensitive); throws `\InvalidArgumentException` if a transport is already registered under that name.
  - `public Network->getTransport(string $name) : ?Transport` - returns a registered transport by name, or `null` if not found.
  - `public Network->getTransports() : array<string, Transport>` - returns all registered transports indexed by name.
  - `public Network->activateTransport(string $name) : void` - marks a registered transport to be started on network startup; throws `\InvalidArgumentException` if the transport is not registered, or `\LogicException` if active transports have already been started.
  - `public Network->getActiveTransports() : array<string, Transport>` - returns all active transports indexed by name.
- The following methods have been deprecated:
  - `Network->registerInterface()` - register a `Transport` with `Network->registerTransport()` instead.
- The following classes have been deprecated:
  - `upnp\UPnP` - deprecated along with `UPnPNetworkInterface` as of Minecraft: Bedrock Edition 1.26.50.
  - `upnp\UPnPNetworkInterface` - deprecated along with RakNet as of Minecraft: Bedrock Edition 1.26.50.

## Internals
- Added a dependency on `axolotl-pm/nethernet` (`^0.3.1`).
- Added the `pocketmine\network\mcpe\nethernet` namespace implementing the NetherNet transport and worker thread:
  - `NetherNetTransport`, `NetherNetInterface`, `NetherNetIdentityKey`, `NetherNetNegotiation`, `NetherNetServerConfigurator`, `NetherNetSignalingFactory`, `NetherNetSignalingContext`, `NetherNetBuiltinSignalingFactory`, `NetherNetThread`, `NetherNetChannel`, `NetherNetIpc`, `NetherNetIpcSignaling`, `NetherNetPacketSender`, `NetherNetSessionListener`, `NetherNetIceConfiguration`, and `NetherNetIceServer`.
  - `NetherNetTransport` provides `addSignaling(NetherNetSignalingFactory $factory) : void` and `setConfigurator(?NetherNetServerConfigurator $configurator) : void` (must be called before NetherNet starts) for plugins extending signaling or customizing `ServerConfiguration`.
  - `NetherNetInterface` provides `acceptOffer(string $networkId, string $offerSdp, ?string $clientAddress = null) : NetherNetNegotiation` for external signaling channels, `getServerInfo() : ServerInfo`, `sendUnreliablePacket(NetworkSession $session, string $payload) : void`, and `setUnreliablePacketHandler(?\Closure $handler) : void`.
- Added `RakLibTransport` and `ServerPongData` (extracted from `RakLibInterface::setName()`).
- `RakLibInterface` and `RakLibTransport` have been deprecated in favour of NetherNet.
  - Added `@internal` `RakLibInterface->getBindAddress() : InternetAddress` and `RakLibTransport::isListeningOn(Network $network, string $ip, int $port, bool $ipV6) : bool`.
  - `RakLibInterface::__construct()` now logs the `pocketmine.server.networkStart` message directly instead of `Server`.
- `NetworkSession::__construct()` now accepts optional `?TransportIdentityKey $transportIdentityKey = null` and `bool $transportEncrypted = false` parameters.
  - Authenticated logins over transports providing a `TransportIdentityKey` now verify that the login chain's client public key matches the transport identity key.
  - The Minecraft-level encryption handshake (`PrepareEncryptionTask` / `ServerToClientHandshakePacket`) is now skipped when the transport layer already provides encryption and client identity verification.
- `Server` now registers `RakLibTransport` (`raknet`) and `NetherNetTransport` (`nethernet`) and starts active transports configured in `transport.name` via `@internal` `Network->startActiveTransports()`.
  - Transport startup failure now throws `NetworkInterfaceStartException` with `Failed to start transport "<name>": <reason>` instead of using `pocketmine.server.networkStartFailed`.
- Removed the `pocketmine.server.networkStartFailed` translation string from `eng.ini` and 8 translation files (`chs`, `fra`, `jpn`, `kor`, `lav`, `rus`, `spa`, `vie`), along with `KnownTranslationFactory::pocketmine_server_networkStartFailed()` and `KnownTranslationKeys::POCKETMINE_SERVER_NETWORKSTARTFAILED`.
- Added 10 new translation keys (`pocketmine.server.nethernet.builtinSignalingDisabled`, `pocketmine.server.nethernet.identityKeySaveFailed`, `pocketmine.server.nethernet.tls.disabled`, `pocketmine.server.nethernet.tls.enabled`, `pocketmine.server.nethernet.udpMuxWithoutPortRange`, `pocketmine.server.raknet.deprecated`, `pocketmine.server.transport.noneConfigured`, `pocketmine.server.transport.unavailable`, `pocketmine.server.transport.unknown`, and `pocketmine.server.upnp.deprecated`) along with their generated `KnownTranslationFactory` and `KnownTranslationKeys` entries, and added `TRANSPORT_*` constants to `YmlServerProperties`.
