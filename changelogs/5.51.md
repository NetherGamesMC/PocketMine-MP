# 5.51.0
Released 27th October 2026.

This is a support release for Minecraft: Bedrock Edition 1.26.60 (display version 26.60).

**Plugin compatibility:** Plugins for previous 5.x versions will run unchanged on this release, unless they use internal APIs, reflection, or packages like the `pocketmine\network\mcpe` or `pocketmine\data` namespace.
Do not update plugin minimum API versions unless you need new features added in this release.

**WARNING: If your plugin uses the `pocketmine\network\mcpe` namespace, you're not shielded by API change constraints.**
Consider using the `mcpe-protocol` directive in `plugin.yml` as a constraint if you're using packets directly.

## General
- Added support for Minecraft: Bedrock Edition 1.26.60 (display version 26.60). (@alvin0319, @IvanCraft623)
- Removed support for earlier versions.

## Gameplay
- Fire, chorus plants and redstone wire now track and persist their connection states as real block states, recalculated on neighbour block updates. (@alvin0319, @IvanCraft623)

## API
### `pocketmine\block`
- `ChorusPlant` and `Fire` now implement `HorizontalConnectable`. (@alvin0319)
- The following methods have been added:
  - `public ChorusPlant->isConnectedAt(int $facing) : bool`
  - `public ChorusPlant->setConnectedAt(int $facing, bool $connected) : void`
  - `public Fire->isConnectedAt(int $facing) : bool` - accepts any facing except `Facing::DOWN`
  - `public Fire->setConnectedAt(int $facing, bool $connected) : void` - throws `\InvalidArgumentException` for `Facing::DOWN`
  - `public RedstoneWire->getConnection(int $facing) : RedstoneWireConnectionType`
  - `public RedstoneWire->setConnection(int $facing, RedstoneWireConnectionType $type) : $this`

### `pocketmine\block\utils`
- The following interfaces have been added:
  - `RedstoneSignalEmitter` - implemented by blocks that can emit a redstone signal, including all `AnalogRedstoneSignalEmitter`s. (@IvanCraft623)
- The following enums have been added:
  - `RedstoneWireConnectionType` (@alvin0319)
